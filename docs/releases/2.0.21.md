## OPCODE 2.0.21

- OpenCode setup failures are now visible and actionable in Voice Action and
  Modes. OPCODE automatically starts or reuses OpenCode's managed service through
  `opencode2 api`, while failed catalog loads wait for an explicit retry instead
  of repeatedly spawning clients.
- OpenCode model pickers can refresh their catalog, so newly connected models
  such as GPT OSS appear without restarting OPCODE. Diagnostic errors are bounded
  and preserve the useful failure detail.
- Website-aware modes fail closed when Brave tab inspection fails instead of
  retaining and applying a stale domain. Configured hosts remain exact, so
  `www.example.com` is no longer silently changed to `example.com`.
- The official `opcode-personal-commands` agent skill can now be installed from
  the OPCODE repository to help coding agents safely configure custom voice
  commands and transcript transformations.
